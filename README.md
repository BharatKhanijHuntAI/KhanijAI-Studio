================================================
  KhanijAI Studio - Mineral Prospectivity Mapping (MPM)
==================================================
**KhanijAI Studio is a desktop application that lets geoscientists apply machine learning to spatial data without writing code.**
**HOW TO RUN:**
1. Double-click 'KhanijAI Studio.exe' to launch the application.
2. The application will open directly in its own standalone window.
3. No Python, terminal, or internet connection is required.

**IMPORTANT:**
- Keep the '_internal' folder next to 'KhanijAI Studio.exe' (it contains the machine learning engines and Python runtime).
- All your exported CSV predictions and models will automatically be saved into the 'outputs' folder.
- Designed for exploration teams and geoscientists.
